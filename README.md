# Etsy Clipart Automation

A personal tool to automate clipart generation and Etsy listings using Kittl and OpenClaw.

## Features
- **Trend Analysis**: Identify top-selling clipart niches on Etsy.
- **Clipart Generation**: Use Kittl to create and post-process clipart.
- **Etsy Listings**: Auto-upload clipart packs with SEO-optimized titles.
- **Order Fulfillment**: Auto-deliver Google Drive links to buyers.
